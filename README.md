# Thuthuka-Nathi
  Thuthuka Nawe is a mobile-first web app that helps young South Africans turn informal experience into a verified skills profile and connect it to real work opportunities.  Many young people have skills they can’t prove: tutoring, helping at a family stall, or learning Excel on YouTube
  Frontend
React, built as a Progressive Web App (PWA)
Tailwind CSS for lightweight, responsive styling
Service workers for offline caching and a low-data mode
Web Speech API for voice input (with text fallback)
Backend and data
 (MS SQL, authentication, and storage)
Python (FastAPI) service for the matching and skills-gap logic
AI and intelligence
LLM API (for example, Claude) to convert informal experience into structured skills, with isiZulu and English support
Verification and messaging
Twilio (or similar) for SMS and WhatsApp reference confirmations
Deployment and security
Vercel for hosting, with HTTPS throughout
Row-level security and role-based access to protect personal data
Environment-based secrets management and POPIA-aligned data handling
Dev tools
GitHub for version control, and Figma for design
